Brent's Method

A hybrid root-finding algorithm combining Bisection, Secant, and Inverse Quadratic Interpolation for guaranteed, fast convergence.

Overview

Brent's method (Richard Brent, 1973) is a root-finding algorithm that guarantees convergence while achieving near-superlinear speed in practice. It intelligently switches between three strategies:

  • Bisection — slow but always converges; used as a safety net.
  • Secant Method — faster (superlinear), uses two points.
  • Inverse Quadratic Interpolation (IQI) — fastest when near the root, uses three points.
Mathematical Foundation

1. Bisection Step

Given a bracket $[a, b]$ where $f(a) \cdot f(b) < 0$, the midpoint estimate is:

$$s = \frac{a + b}{2}$$

Guaranteed to halve the interval each step. Convergence is linear.

2. Secant Step

Uses a linear interpolation between the two most recent points $a$ and $b$:

$$s = b - f(b)\cdot\frac{b - a}{f(b) - f(a)}$$

Convergence is superlinear (order $\approx 1.618$, the golden ratio) near the root.

3. Inverse Quadratic Interpolation (IQI)

Fits an inverse quadratic through three points $(a, f(a))$, $(b, f(b))$, $(c, f(c))$ and evaluates at $y = 0$:

$$s = \frac{af(b)f(c)}{(f(a)-f(b))(f(a)-f(c))} + \frac{bf(a)f(c)}{(f(b)-f(a))(f(b)-f(c))} + \frac{cf(a)f(b)}{(f(c)-f(a))(f(c)-f(b))}$$

Convergence is cubic when well-conditioned.

4. Decision Logic (When to Bisect)

The algorithm uses the faster step (IQI or Secant) only when ALL of the following hold; otherwise it falls back to Bisection:

  • $s$ lies strictly between $\tfrac{3a+b}{4}$ and $b$
  • If mflag is set: $|s - b| < \tfrac{|b - c|}{2}$ and $|b - c| \geq \delta$
  • If mflag is not set: $|s - b| < \tfrac{|c - d|}{2}$ and $|c - d| \geq \delta$

where $\delta$ is the tolerance and $d$ is the previous value of $c$.

5. Convergence Criterion

$$|b - a| < \delta \quad \text{or} \quad f(b) = 0$$
Algorithm Summary
  • Initialize with bracket $[a, b]$ satisfying $f(a)\cdot f(b) < 0$. Swap if $|f(a)| < |f(b)|$ so that $b$ is always the better guess.
  • Set $c = a$, $\text{mflag} = \text{true}$.
  • Compute $s$ via IQI if $f(a) \neq f(c)$ and $f(b) \neq f(c)$, else via Secant.
  • Check the 5 conditions. If any fails, use Bisection and set mflag = true; else set mflag = false.
  • Evaluate $f(s)$. Update bracket: set $d=c$, $c=b$. If $f(a)\cdot f(s) < 0$ then $b=s$, else $a=s$.
  • Swap $a,b$ if $|f(a)| < |f(b)|$. Check convergence. If not converged, go to step 3.
Example 1 — Find the root of $f(x) = x^3 - x - 2$

We seek a root on the interval $[1, 2]$. Note:

$f(1) = 1 - 1 - 2 = -2 \qquad f(2) = 8 - 2 - 2 = 4$

Since $f(1) \cdot f(2) = (-2)(4) = -8 < 0$, a root exists in $[1, 2]$. The true root is $x \approx 1.5213797$.

Step-by-Step: Iteration 1

  • $a = 1,\ b = 2,\ f(a) = -2,\ f(b) = 4$. Since $|f(b)| < |f(a)|$ is false, no swap.
  • $c = a = 1,\ \text{mflag} = \text{true}$. Since $f(a) = f(c)$, we cannot use IQI. Use Secant: $$s = 2 - 4\cdot\frac{2-1}{4-(-2)} = 2 - \tfrac{4}{6} = 1.\overline{3}$$
  • Check conditions: $s = 1.333$ is between $(3(1)+2)/4 = 1.25$ and $2$ ✓, but mflag is true and $|s-b| = 0.667 \geq |b-c|/2 = 0.5$ — condition fails → Bisect instead: $s = (1+2)/2 = 1.5$.
  • $f(1.5) = 1.5^3 - 1.5 - 2 = 3.375 - 1.5 - 2 = -0.125 < 0$.
  • $f(a)\cdot f(s) = (-2)(-0.125) = 0.25 > 0$, so $a \leftarrow s = 1.5$. Bracket becomes $[1.5, 2]$.

Step-by-Step: Iteration 3 (IQI)

  • $a = 1.5,\ b = 1.5384615,\ c = 2$. $f(a)=-0.125,\ f(b)=+0.0757,\ f(c)=+4$. All three values distinct → use IQI.
  • $$s = \frac{1.5 \cdot (0.0757)(4)}{(-0.125-0.0757)(-0.125-4)} + \frac{1.5385 \cdot (-0.125)(4)}{(0.0757+0.125)(0.0757-4)} + \frac{2 \cdot (-0.125)(0.0757)}{(4+0.125)(4-0.0757)}$$ $$\approx 1.5214$$
  • Conditions pass → accept $s = 1.5214$, mflag = false.
  • $f(1.5214) \approx +0.0007$. Since $f(a)\cdot f(s) < 0$, set $b = 1.5214$. New bracket: $[1.5, 1.5214]$.
✓ Root found: $x \approx 1.5213797$ with $f(x) \approx 0$ after 5 iterations.
Example 2 — Find the root of $f(x) = e^x - 3x$

We seek a root on $[1, 2]$. Check the bracket:

$f(1) = e^1 - 3(1) = 2.71828 - 3 = -0.28172$ $\qquad f(2) = e^2 - 3(2) = 7.38906 - 6 = 1.38906$

$f(1)\cdot f(2) < 0$ ✓. The true root is $x \approx 1.5121345$.
